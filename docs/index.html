这套预设在解决什么

ChatGPT / Codex 高频操作太散：切模型、调推理、管多任务、点审批、再唤起语音。TourBox 把它们收成一套手感。

旋钮管任务

在活跃任务间快速切换，不必在侧边栏里点来点去。

滚轮调推理

按住侧键滚滚轮，提高或降低推理强度，边聊边调。

按键做决策

YES / Approve 与 NO / Decline 就在拇指区，审批不停手。

一键进场景

Tour / C1 / C2 分别打开 Codex、ChatGPT、Work 新对话。

重点推荐

为什么左上横键要做成「全局说话」

ChatGPT / Codex 自带语音很强，但只在应用内生效。真正卡住节奏的，往往是你在别的窗口想到一句指令，还得切回 ChatGPT 再点麦克风。

建议把 Top（左上横键） 改成 微信输入法语音，并设成全局快捷键。任意窗口按一下就能说，文字落入输入框后再交给 Codex。

  1. 在微信输入法设置里确认语音快捷键。
  2. 在 TourBox Console 选中本预设的 Top / 左上横键。
  3. 映射成与微信输入法语音相同的快捷键。
  4. 设为全局触发（或默认 / 全局预设），离开 ChatGPT 也能用。

横键适合按住说话 / 点按唤起，位置固定，盲按不易误触。

默认 vs 推荐

ChatGPT 内置语音

适合在 App 里连续对话、指挥 Agent。

微信输入法语音（推荐）

适合全局口述，任何输入框都能落字。

两者可并存：横键管全局说一句，需要全双工 Voice 时再进 ChatGPT。

如何导入与微调

官方库已审核通过；下载后按自己的快捷键习惯改几下即可。

  1. 下载预设

    从 TourBox 官方分享页 或本页 .tb 下载。

  2. 导入 Console

    TourBox Console → 预设列表 → 导入，绑定到 ChatGPT。

  3. 核对快捷键

    若你改过 ChatGPT / Codex 快捷键，在对应按键上对齐。

  4. 按手感重排

    YES / NO 可对调；左上横键建议保留给全局语音。

  5. 打开 HUD（可选）

    初学打开 HUD，熟悉后即可盲操。
